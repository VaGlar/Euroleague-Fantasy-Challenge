# 003 — Βαθμονόμηση των υψηλών προβλέψεων

**Ημερομηνία:** 28/9/2026 · **Κατάσταση:** ❌ απορρίφθηκε (δεν υπάρχει σταθερή υπερεκτίμηση να διορθωθεί)

## Ερώτημα
Στο πείραμα 002 οι 20 κορυφαίοι κάθε αγωνιστικής φάνηκαν να προβλέπονται ~7% πάνω απ' όσα έφεραν («κατάρα του νικητή»). Πρέπει να διορθώσουμε (βαθμονομήσουμε) τα νούμερα που βλέπει ο χρήστης;

## Μέθοδος
- **Pool υποψηφίων:** κάθε αγωνιστική, όσοι είχαν εμφανιστεί σε box score πριν από αυτή (κοινός κώδικας `research/_lib.py`).
- **Μέτρηση μόνο σε όσους ήταν στη 12άδα.** Στην πραγματική λειτουργία οι απουσίες και οι τραυματισμοί καλύπτονται από τα νέα και το παιχνίδι, ενώ στο backtest όχι. Αν τους μετρούσαμε, θα «διορθώναμε» διπλά.
- **Δύο διορθώσεις**, με εκπαίδευση στο πρώτο μισό της σεζόν και έλεγχο στο δεύτερο:
  - γραμμική (`a + b·xPTS`), που αλλάζει μόνο τα νούμερα που φαίνονται, όχι τις επιλογές,
  - ισοτονική (μονότονη καμπύλη), που μπορεί να αλλάξει και τις επιλογές ομάδας.
- **Δύο σεζόν:** 2025–26 και 2024–25.

## Αποτελέσματα (δεύτερο μισό κάθε σεζόν)

| | 2025–26 | 2024–25 |
|---|---|---|
| Top-20: πρόβλεψη → πραγματικό | 17,90 → 17,17 (**+4%**) | 18,23 → 18,56 (**−2%**) |
| Μέσος όρος όλων: πρόβλεψη → πραγματικό | 8,01 → 8,43 | 7,59 → 8,23 |
| Γραμμική διόρθωση (a, b) | 1,20 + 0,90·xPTS | 0,97 + 0,95·xPTS |
| RMSE: χωρίς → γραμμική | 7,411 → 7,399 | 7,277 → 7,250 |
| Πόντοι ομάδας/αγωνιστική: χωρίς → ισοτονική | 149,9 → 146,1 (−3,8 ± 4,8) | 161,1 → 148,9 (−12,2 ± 10,5) |

## Συμπεράσματα
- **Η υπερεκτίμηση των κορυφαίων δεν είναι σταθερή:** +4% τη μία σεζόν, −2% την άλλη. Το +7% του 002 μετρήθηκε σε άλλο pool (μόνο όσοι έπαιξαν σε εκείνη την αγωνιστική) και δεν αναπαράγεται.
- **Σταθερό είναι μόνο ένα μικρό συνολικό «χαμήλωμα»:** ~0,5 PIR κάτω, για όσους ήταν στη 12άδα. Οφείλεται κυρίως στο ότι οι απουσίες μετράνε στο ιστορικό, και στην πραγματική λειτουργία καλύπτεται από τα στοιχεία διαθεσιμότητας.
- **Η ισοτονική διόρθωση χειροτερεύει τις επιλογές** και στις δύο σεζόν, αν και μέσα στο στατιστικό περιθώριο.

## Απόφαση
Καμία βαθμονόμηση. Τα νούμερα του μοντέλου μένουν όπως είναι. Το «+7%» του 002 διορθώνεται εδώ ως μη σταθερό εύρημα.
